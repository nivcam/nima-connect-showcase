# Screenshots — Publication Guidelines

[← Showcase home](../README.md)

This public showcase is intentionally **documentation-first**. Real screenshots can be added once they have been reviewed and approved for publication.

## Suggested gallery

| Screenshot | What it should demonstrate |
| :--- | :--- |
| CRM overview | Overall navigation and customer workflow organization. |
| Shared Inbox | Conversation handling and the messaging experience, using demo data only. |
| Sales pipeline | Lead stages and management workflow, using synthetic contacts and amounts. |
| Module settings | Organization-level configuration, with any identifiers redacted. |

## Before uploading

1. Capture the screen from a **demo environment or with synthetic data**, preferably not from a real client account.
2. Remove customer and employee names, phone numbers, email addresses, photos, message content, financial data, and identifying records.
3. Exclude session identifiers, browser query tokens, credentials, QR codes, internal domains, IP addresses, and infrastructure controls.
4. Review the image for incidental disclosures (browser tabs, bookmarks, notifications, developer tools, and timestamps).
5. Get approval from the relevant rights holder when brand, client, or third-party information might be visible.
6. Confirm the image genuinely depicts the application and isn't a fabricated interface presented as a screenshot.

For privacy, **synthetic/demo content is better than blurring real customer information** when practical.

## Planned file organization

Approved screenshots can later be stored under the public repository's assets/screenshots/ directory, using descriptive file names and clear alt text.

This file does not imply any screenshots have already been uploaded.
